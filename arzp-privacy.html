ARZP — Privacy Policy

Effective date: 8 November 2026

ARZP is a Windows desktop application developed by Vadym Horokh. This policy explains how ARZP handles data, including data obtained through Google APIs.

Data stored by ARZP

All data entered into ARZP (businesses, employees, schedules, timesheets, payments) is stored only in files on the user's own computer, in the program folder. ARZP has no server and the developer does not receive, collect or store any of this data.

Google user data

  • Signing in with Google is optional. ARZP requests only the drive.file scope: access to the files that ARZP itself creates in the user's Google Drive. ARZP cannot see or change any other files of the user.
  • ARZP uses this access only to create folders and Google Sheets in the user's Drive and to write the payroll sheets that the user creates in the program.
  • The sign-in token is stored only on the user's computer. Google user data is not sent to the developer or to any third party, is not sold, and is not used for advertising or for training AI models.
  • ARZP's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

The user can sign out in ARZP (☁ GOOGLE → ВИЙТИ), revoke access at myaccount.google.com/permissions, delete the files ARZP created in Google Drive, and delete the program folder from the computer.
